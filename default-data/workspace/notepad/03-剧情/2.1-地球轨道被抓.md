# 2.1 地球轨道被抓

Aliya在地球轨道排队等待入港，雷达警报——一队不明飞船靠近，型号XM-380（安保专用），无识别码。

Aliya试图引用[[定居星系法]]抗议但信号被封锁。飞船系统控制权被夺取。她关闭整个动力系统（对方没法调用摄像头和传感器），然后躲藏。玩家联系[[警察]]（编号1865），警方派出飞船，随后以"不可抗力"取消。

安保在医疗室找到昏迷的Kane并搬上船，然后找到了Aliya。

安保对话："为了抓这么个小家伙花了这么多时间。都要赶不上剧集开播了。""没事，一会儿开快点。几十分钟就能回去。多的燃料费算我的。"

平板（[[玩家]]载体）被一并收缴。

**分支**（躲藏地点）：实验室（收纳隔间）/ 仓库（板条箱/垃圾处理器）/ 引擎舱（墙壁线路，高温差点晕厥）
