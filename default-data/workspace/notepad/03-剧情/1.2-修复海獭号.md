# 1.2 修复海獭号

Aliya在玩家指导下修复海獭号紧急问题。

**制氧机**：二氧化碳制水完全坏掉，电解水部分是小问题。排除故障后没启动——原来是玩家远程启动了它。玩家拥有COSMOS系统级别权限。

**动力室**：动力炉异常高压，整个房间像大火炉。Aliya是生物学家，机械是Kane专长。翻手册找到方案（强行启动引擎泄压，可能爆炸），玩家建议直接破坏压力阀。Aliya选择相信玩家，成功。

修完后Aliya："一只重新复活的海獭！这全部是仰仗我这位天才工程师。"玩家吐槽她刚说自己是生物学家。Aliya："哼哼，可别小瞧我。我可是有飞船维修工八级证书的。"Kane是特级。

**新信息**：曲率引擎因通讯损坏被禁用；玩家知道密钥（来自父亲飞船计算机解算）；收音机收到未知信号。
