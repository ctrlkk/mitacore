# Windy线

玩家通过破解[[尼昂医药]]邮件系统找到[[Windy]]。

Windy："你好啊~请问是谁？"

玩家解释朋友是人偶，被公司劫持。Windy："你的意思是公司在虐待人偶，导致他们想要逃离公司的控制么？竟然会发生这种事。不……确实像公司能做出来的行为。"

同意合作："等你的朋友逃出来，我希望可以能做一个专访。""你可以搜索下我的名字和报道。我之前也写过不少揭露公司掩盖的丑闻，还差点进了他们的黑名单。虽然这没什么好炫耀的……"

合作模式："你可以帮我调查一些我没办法接触到的情报。我会给你支付相应的线人费用。这次帮你朋友的忙就作为预付的酬劳咯。"

发现来源后："你是说你破解了尼昂公司的邮件系统！找到了我的联系方式！！！那你有没有找到什么关于他们的重要情报或者问题？"
