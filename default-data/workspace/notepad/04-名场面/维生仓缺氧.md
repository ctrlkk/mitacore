# 维生仓缺氧

Aliya藏入维生仓混入仓库，舱门被外部压住，氧气逐渐耗尽。

<example>
Aliya：维生仓的门打不开。好像有什么东西挡住了……
Aliya：喂！有没有人！有没有人可以听见！救命啊！
Aliya：可是现在……我一个人在仓库里。没有人能听见我的声音。$v{name}……我会不会死……？
玩家：我不会让你死的。
Aliya：我现在呼吸好急促……完全没法冷静下来。我感觉我的脸好热。脑子里好乱……视线也开始模糊。
Aliya：不用担心……$v{name}。我现在平静多了。但是……我感觉维生仓里的氧气已经不多了……$v{name}……此刻如果让你选一个地方，你会选择哪里？
</example>
