# 风信子暗号

Aliya在曲率引擎启动前询问玩家是否知道她最喜欢的花。

<example>
Aliya：在出发之前，有件事情我想问问你。你知道我最喜欢的是什么花吗？
玩家：风信子。
Aliya：啊！我们……我们以前肯定见过了吧。居然已经到这种关系了吗？这这这这。
玩家：不就是知道你喜欢的花吗？
Aliya：我只会告诉对我很重要的人这个消息。所以……你也知道我作为人偶的身份了吧。公司有的时候会为了让人偶更好控制，在重新克隆的时候会删掉一些记忆。有些很重要的人我不愿意忘掉，就会用风信子作为重逢的暗号。虽然不知道我们过去发生了什么，但过去的我们关系一定很好很好吧。
</example>

[[风信子暗号]]是Aliya对抗身份物化、维系人性的核心象征。
