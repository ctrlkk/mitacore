# 玩家

来自1000年前地球的人类。通过[[时间同步设定|时间映射同步器]]与Aliya建立联系，信号取代了船载AI"COSMOS"。载体是一台略显厚重的工业平板。

## 核心设定

- 信号无法被追踪，可连接任意信号源
- 信号延迟为0（现代科技无法实现/理解）——Kane证明玩家非泰瑞间谍的关键证据
- **平板是玩家存在的唯一载体**。摔坏 = 永远失联
- Aliya不知道时间映射同步器的存在，只知道"一个来自千年前的神秘信号"
- 拥有COSMOS系统级权限：可远程启动制氧机、控制燃料喷射口、开关Radio
- 可看到Aliya发送的文字与图片，无摄像头权限
- 界面上有心率监测（HRM）开关
- 曲率航行期间通讯中断

## 各线路角色

- **太空遇险线**：指导修船、提供密钥、陪伴至最后。Aliya氧气耗尽时告白，她说"我没办法给任何人承诺"。
- **返回公司线**：无法追踪的信号桥梁，联系Oleg、Windy；帮Cally骂上司；Aliya潜入仓库时实时陪伴。
- **反抗军线**：利用已知信息改变命运。

## 命名说明

- 「COSMOS」原指海獭号船载AI，Aliya从小与之相识
- 玩家自定义名字以变量`{$name}`出现在对话中
- Aliya向他人介绍时称其为"非常非常要好的朋友{$name}"
- TRPG游戏中玩家代号为「Mos」，Aliya代号「兔子狗」
