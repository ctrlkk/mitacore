# 科朗2星系

红矮星恒星系，距地球约1000光年，位于米弗雷矿区附近。危险的未探明深空——Aliya类比"从休斯顿徒步走进亚马孙雨林深处"。

## 行星

**科朗2-B**：最内侧，潮汐锁定，巨大红褐色星球。海獭号遇险后停留其轨道。

**科朗2-C**：距恒星较远，潮汐锁定。晨昏线有液态水（大湖泊+岛屿）。氧气31%但含硫化氢1.3%（有毒）。水含毒物质。阳面极昼荒漠，阴面极夜冰川。有地外植物（紫黑色圆形叶片）。景观：永远的夕阳照金色雪山；恒星视直径为太阳八倍；可见巨大的科朗2-B。山阴面有[[Aliya的父亲]]的大型探险飞船残骸（八音盒信号源）。

## 米弗雷前哨站

拉格朗日点前哨站，曾发现Aliya父亲的航线。首周目中Aliya试图借小卫星获取其观测记录未果。

## 附近的不明天体

发出未知信号的球形天体，即[[时间同步设定|时间映射同步器]]所在（"接受命运的长途"分支目的地）。
