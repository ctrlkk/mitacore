# 海獭号

泰瑞远航部科考船。船员：[[Aliya]]（生物学家）、[[Kane]]（工程师）、[[Ryoko]]（船长）。实际上是未经审批开走的（逃跑计划）。

## 名称由来

来自地球鼬科动物海獭——海面睡觉时手牵手防止飘散。寓意船员在星海中团结互助。

## 舱室与设备

动力室（动力炉、压力阀）· 制氧机（二氧化碳制水 + 电解水）· 培育室（控温，存放兔子狗样本）· 实验室 · 居住区 · 休眠舱（类似冬眠，最多3~6个月）· 曲率引擎 · Radio收音机（玩家可控）· 水循环过滤系统

## 关键事件

- 科朗2被小陨石砸中，船体严重受损
- 曲率引擎因通讯系统损坏被禁用
- 地球轨道被泰瑞安保（XM-380型）拦截，系统控制权被夺取
- 平板（[[玩家]]载体）被一并收缴
