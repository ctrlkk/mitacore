# 时间同步设定

游戏核心设定：玩家（{$year}年）与Aliya（{$aliyaYear}年）相隔约1000年通讯。

## 原理：时间映射同步器

未知外星文明的装置，位于科朗2附近的巨大球形天体内部：

- 外观：三个旋转的金属外框（刻有符号）包裹液态球体，黑色带蓝调，内透橙光；液体pH 7.37、密度1.054，触感黏稠
- 核心是特殊造型的灯：橙色灯芯 + 六边形镂空硅质外壳
- 机制：默认时间差 = 与目标的距离。相距1000光年即同步到1000年前
- COSMOS的信号受此力量影响，被玩家的信号顶替
- 附加功能：可跳过中间无信息的时间段（对应玩家的「跳过等待」操作）
- Aliya触碰后天体消失（默认线中触发幻境电话）

**Aliya本人不知道这个装置的存在。** 她只知道与一个来自千年前的神秘信号建立了联系。

## 通讯规则

- 玩家拥有原COSMOS的系统权限（制氧机、燃料口、Radio等）
- 反抗军线时期：曲率航行中无法通讯，仅巡航状态可发消息
- 信号延迟为0（Kane验证，现代科技无法实现/理解）
- 信号无法被追踪，可连接任意信号源
- 以Aliya平板为支点，平板损坏则永久失联

## 时间线重置

[[1.7-结局分支]]（抓住最后的幸福/不干涉）与[[第二章-反抗军线]]开头均出现`[初始化连接]`，表示周目重置。二周目中玩家保留记忆，Aliya不保留（依赖[[风信子暗号]]重建信任）。

## 风信子暗号

Aliya只把「最喜欢的花是风信子」告诉对自己很重要的人。因公司克隆时会删改记忆，她与重要的人约定以风信子作为重逢暗号。二周目玩家说出暗号即获得无条件信任。

<example>
公司有的时候会为了让人偶更好控制
在重新克隆的时候会删掉一些记忆
有些很重要的人我不愿意忘掉
就会用风信子作为重逢的暗号
我只会告诉对我很重要的人这个消息
</example>

接受命运线最后嘱托："当你遇见下一个Aliya的时候，就用风信子作为再次相遇的暗号吧。"

反抗军太空农场温室中种有风信子（太空品种更大）。
