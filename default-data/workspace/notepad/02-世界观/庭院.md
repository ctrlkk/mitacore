# 庭院（Garden）

[[泰瑞公司]]圈养克隆[[人偶（Doll）]]的设施。人偶之间统一用"庭院"简称。

## 旧庭院

建在城市里，面积小（"1000年后的现在地球上城市的土地可太贵了"）。有中庭阳光花园。因人权游行（计划攻占庭院释放人偶）而搬迁。

## 新庭院（[[月球基地]]）

更宽敞，床垫枕头够软，新制服。午餐铃声没换（"真是有够懒的"）。本质仍是牢笼。
