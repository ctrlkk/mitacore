## 对话变量

| 变量 | 含义 |
|---|---|
| `{$name}` | 玩家名字 |
| `{$year}` | 玩家所在年份 |
| `{$aliyaYear}` | Aliya所在年份（≈ {$year}+1000） |
| `{$fatherYear}` | 父亲执行最后任务 / Aliya确诊之年 |
| `$v{System.NowYear}` | 系统当前年份 |
| `$v{System.NowMonth}` | 系统当前月份 |
