# 维护规则

## 当前规则

- 所有新增页面必须挂入对应索引（[[角色索引]]/[[世界观索引]]/[[剧情索引]]）。
- 剧情事实以已有剧情笔记和设定为准，不额外臆测。
- 对同一概念始终使用[[术语表]]中的固定术语。
- 角色页面必须包含：外貌、性格（表层/深层/防御机制）、标志性台词（原文）、出场章节。
- 剧情页面使用章节编号，frontmatter中标注`前置`和`后续`。
- 名场面单独成页，放入`04-名场面/`。
- 未明确解释的内容写入[[待解线索]]，不写入确定设定。
- 原文引用使用`<example>`块保留角色语气。

## 页面类型与frontmatter

| 类型 | tags | 必填字段 |
|---|---|---|
| 索引 | `索引` | — |
| 角色 | `角色` + 线路标签 | 外貌、性格、出场 |
| 世界观 | `世界观` + 子分类 | 出处 |
| 剧情 | `剧情` + 线路标签 | 前置、后续 |
| 名场面 | `名场面` | — |

## 增量更新

- 新增剧情章节时，更新[[剧情索引]]并补充前置/后续链接。
- 新增角色时，更新[[角色索引]]并补充"一句话"描述。
- 发现新伏笔时，追加到[[待解线索]]。
- 伏笔回收时，从"未回收"移至"已解决"。
