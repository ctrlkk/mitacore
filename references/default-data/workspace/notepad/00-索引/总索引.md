# 总索引

《彼方的她》是对话类多分支视觉小说。玩家是1000年前地球的人，通过一台工业平板跟1000年后的人偶Aliya通信。核心体验：你碰不到她，救不了她，只能陪她说话。

## 两条主线

**wiki1（太空遇险线）**：飞船被陨石砸中→修船→探索→发现父亲遗骸→生死抉择。三个结局：接受命运 / 抓住最后幸福 / 反抗军。

**wiki2（返回公司线）**：Aliya回公司救Kane→地球轨道被抓→月球基地醒来→制定逃跑计划→潜入仓库→被抓（Demo结束）。同时玩家在外部联系Cally、Oleg、Windy。
