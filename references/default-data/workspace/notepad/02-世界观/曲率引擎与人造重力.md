# 曲率引擎与人造重力

重点：两者**同源**。在卡西米尔效应腔中通过量子真空涨落产生负能量，弯曲时空曲率。作用于飞船前方 = 曲率航行；作用于所处空间 = 人造重力。

## 曲率引擎

- 星际航行完全依赖它
- 受公司密钥和通讯系统锁定管控
- 低阶：星系内短途（数分钟）；高阶：跨恒星系跃迁
- 曲率航行期间通讯中断
- 通讯系统被破坏时禁止使用
- 密钥：`0XA89BC52E`（反抗军线由父亲飞船AI算出）

## 游戏攻略向

- 张力性气胸：第二肋间（答错→Kane死亡）
- 压力阀：直接破坏（强启引擎有爆炸风险）
- 修理顺序：制氧机→动力室（培育室温度随动力室恢复）
- 科朗2-C降落喷射时长：15秒（短→坠毁阴面冰川，长→坠毁阳面荒漠）
