# 新柏林市

地球赤道港口城市，隶属地球联邦赤道特别行政区。以太空电梯"赫尔墨斯柱"地面终端为核心。3024年常住人口约1850万，面积2312.5平方公里，东西狭长，南临太平洋。

2387年港口启用，2417年电梯竣工，2455年获自治宪章。经济支柱：港口物流、星际贸易金融、赤道重工业、太空旅游。港口日均处理货物15万吨、旅客6万人次。

市内划分：港口区、工业物流带、中央商务区、居住混合区。东北部[[新维加斯区]]是娱乐与会议特区。

政治：市政府有自治权，但联邦太空电梯管理委员会直接控制港口安全与运营。

年度活动："缆索节"、新柏林国际电影节。
