# 米弗雷联合体

定居星系群第二大跨星际企业集团，[[泰瑞公司]]主要对手。截至3024年年营收约3.2亿亿信用点，控制约30%外围殖民地经济。

"米弗雷"源于19世纪挪威一艘小渔船。船主埃里克·米弗雷（1798–1836）英年早逝，无直系继承人。品牌历经数十代职业经理人经营：渔业→沿海运输→修船厂→22世纪抓住[[新柏林市]]太空电梯机遇转型物流。24世纪伊尔莎·格雷通过管理层收购正式成立"米弗雷联合体"，确立去个人化永续治理。

面对泰瑞在太阳系的垄断，米弗雷转向外围殖民地（半人马座、天狼星等），建立"盟友-承包商"网络。三次企业战争（2791–3015），3015年停战后冷和平。自称"边疆自由的捍卫者"。

## 特征

- 工厂安保严密（哨塔、高墙、安保机器人）
- 医疗技术较泰瑞差
- 加密技术差（Aliya吐槽"米弗雷的加密这么差劲的吗"）
- 生产调整睡眠周期的药物
- 防护服装备优于泰瑞（带喷气推动靴）
