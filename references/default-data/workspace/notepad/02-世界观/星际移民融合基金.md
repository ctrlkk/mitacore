# 星际移民融合基金

3023年[[新柏林市]]政府设立，帮助通过新柏林港进出地球圈的移民适应本地生活。提供语言培训、职业认证、住房低息贷款。资产规模约420亿信用点（3024年）。

资金来源：市财政拨款、联邦补贴、"移民债券"（年化5.8%–7.2%）。投资组合45%配置高收益星际资产支持证券（底层：星际运输应收款、地外住房抵押贷款、[[新维加斯区]]赌场消费信贷），预期回报率12%。

截至3024年服务约12万移民。**风险**：可持续性高度依赖星际贸易景气度与地外房地产升值。移民净流入增速已从9%降至4%。高收益资产平均杠杆率约1:8。联邦审计署内部文件指出若星际运费下降20%或再融资受阻，可能面临流动性缺口。市政府计划3025年继续超额发行。
