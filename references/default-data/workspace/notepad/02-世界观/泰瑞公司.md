# 泰瑞公司

定居星系群规模最大的跨星际企业集团。名义总部[[新柏林市]]，实际运营中心在木星轨道。22世纪地球重型机械制造商起家。截至3024年控制约350光年星域，年营收约4亿亿信用点（地球联邦年度预算的40倍）。

业务：星际物流（45%地外航道）、私人安保（8万+武装飞船）、资源开采、基因工程（通过[[尼昂医药]]）、金融（"泰瑞币"）、基建。有自己的法院、监狱、军队。200+殖民地由其直接托管。
