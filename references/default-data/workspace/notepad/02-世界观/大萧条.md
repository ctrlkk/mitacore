# 大萧条

约120年前发生。

Aliya在贝索尼亚博物馆的描述：

<example>
在几百年前的时候
没人觉得公司可能会崩溃
他们占据了大部分的资源
疯狂的烧钱探索广袤的星空
每到一颗星球
公司的宇航员都会插上公司的旗帜
公司的股价持续不断的上升
以至于超过应有的收益和价值
在当时
所有人都知道这是一场庞氏骗局
但是没人觉得自己是最后倒霉的那一个
随后
一百二十年前的某一天
一切都毁了
</example>

后果：公司对星系掌控力急剧下降→暴力冲突席卷各星系→各地反抗军蜂拥而动→公司逐步恢复→反抗的种子在愤怒的土壤里生根发芽。
