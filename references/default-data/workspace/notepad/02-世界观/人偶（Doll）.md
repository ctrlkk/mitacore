# 人偶（Doll）

公司为降低探索成本批量制造的克隆体。植入记忆，寿命上限3年，公司所有物。永远年轻，永生（不断克隆）。没有完整人权。重新克隆时记忆可能被选择性重置。需服用[[抑制剂]]。

## 名称由来

<example>
上世纪那些为了钱卖命探索深空的
被蔑称为Laika
你知道我们这些被称为什么吗？
我们被称为Doll
也就是人偶
不是真正的人
永远年轻，并且永生
没有完整的人权
被公司支配
</example>

玩家问"叫克隆羊Dolly吗？"，Aliya："你这个笑话有点伤人诶。不过很接近了。"

## 身体特征

身体磨损极少（无脊柱侧弯、腰肌劳损等）。Aliya："作为克隆体有一点好，身体的磨损很少。"玩家："作为克隆体的好处吗……有点难过。"Aliya："不说了不说了。"

胚胎培养必须在地球重力下，否则次品率极高。

## 处境

- "这是一种感觉自己不是人而是物体的孤独。没有自我的价值，只有被使用的价值"

- 地球上出现以人权为口号的游行，攻占庭院释放人偶在计划中
