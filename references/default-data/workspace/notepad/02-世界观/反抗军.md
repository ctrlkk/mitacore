# 反抗军

弱小的反抗组织，目标：颠覆公司统治。

## 关键人物

- [[Leon]]：队长，前米弗雷语文老师
- [[Penny]]：成员

## 策略

"行大善需容小恶。"与泰瑞南翼合作发动内战以获取技术和装备。

## 内部问题

部分成员认为复制人和人类有界限："我们这些复制人只需要做好本职工作就好了。因为我们是人造的，所以没有灵魂。"Aliya听到后差点和人打起来。
