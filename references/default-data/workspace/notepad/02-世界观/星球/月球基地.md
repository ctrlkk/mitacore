# 月球基地

新[[庭院]]所在地。

## Kane的推断依据

1. Aliya从被抓到醒来只隔约78分钟，太阳系内合理选项有限
2. 月球重力为地球1/6，需补充的重力比火星多1.3倍，但燃料成本仅高约14%
3. 月球是太阳系氦-3主要产地，大幅降低人造重力成本
4. 月球上只有泰瑞自己的矿场，无居民或第三方
5. 人偶胚胎必须在地球重力下培养

氦-3来自太阳风。条件：离恒星够近 + 无大气层。太阳系内只有月球和水星满足，水星离太阳太近，只能是月球。

## 设施

仓库（仓储区）· 食堂 · 寝室 · 通风管道系统 · 卸货区 · 武器库 · 备用电路
