# 尼昂医药

[[新柏林市]]最大医药企业，总部在中央商务区。专注星际移民适应性药物与基因调节产品，占联邦抗太空辐射药物市场约78%。3024年年营收超900亿信用点，净利润率34%–40%（行业平均的三倍）。

## 重点：泰瑞的傀儡

约67%经济受益权通过三层离岸特殊目的载体最终指向[[泰瑞公司]]。董事会主席由泰瑞前高级副总裁担任。公司官方坚称"不存在任何形式的控制关系"。

## 运营问题

- 核心药物专利保护期延长至34年（联邦标准20年）
- 持有赤道地区大量基因序列独家使用权，部分来源于移民体检中未明确征得同意的生物样本
- 3021年被披露在[[新维加斯区]]地下实验室对流浪者进行人体药物测试
- 联邦反垄断局3019年调查，尼昂承诺"急诊药物降价5%"后结案
- 年游说经费约8亿信用点
