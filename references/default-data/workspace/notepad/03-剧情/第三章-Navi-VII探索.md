# 第三章 · Navi VII探索

Aliya和[[Penny]]前往废弃矿业星球[[Navi-VII]]执行资源勘察。[[Leon]]任务简报："这颗星球曾经是一颗专精于矿产开发与冶炼的星球，但是四十多年前一场生态灾难导致其被废弃。"

Penny用游隼号无人机监控。求救呼号2-1-3-7。

## 三个搜索地点（玩家选其一）

**医院线**：肺病和皮肤病记录，疾病从矿工扩散到全体。报告被上级回复："你不是地质学家，这份报告不具有对矿脉开采计划的指导价值，建议永久封存。"

## 拉姆石

Aliya发现火山灰中的[[拉姆石]]，解释"音译成地球法语是爱的意思。赠送一块拉姆石，意思就是我爱……我……呃……"玩家："你的心跳得好快。"Aliya："我……我我我……哪有心跳得那么快！你快把那个关掉！"
