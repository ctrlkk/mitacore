# 1.4 发现兔子狗

通风管道传来声音。Aliya躲进实验室，拉两个仪器围在墙角，手里捏撬棍——"我感觉我现在像是恐怖电影里面的女主角"。

声音越来越近，数据板被撞飞。Aliya突然说"因为我已经不是Aliya了"。玩家大惊。Aliya坏笑："哼哼~没错，Aliya的身体已经被我霸占了。"

原来是培育室的[[兔子狗]]跑出来了（样本4782E第五批次）。因为喜欢[[菲涅尔矿石]]的味道才跑到实验室。

Aliya解释兔子狗：人造培育物种，外表可爱但实际是原星球顶级掠食者，繁殖极差，基本都是克隆的。主要用于矿坑探索——"虽然矿洞风险很大，但兔子狗毕竟便宜。"

**新信息**：兔子狗是克隆的；菲涅尔矿石稀有值钱；公司财产制度（勘探发现归公司）。
