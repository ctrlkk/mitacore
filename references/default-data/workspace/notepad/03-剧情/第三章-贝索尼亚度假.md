# 第三章 · 贝索尼亚度假

Aliya随[[Leon]]等人前往[[贝索尼亚]]。表面度假，实际是Leon策划的刺杀泰瑞南翼主管行动。Aliya不知情。

## 度假日常

- 海边堆沙堡"女皇Aliya的不落城堡"
- 旅行者1号博物馆。Aliya念墙上纪念文段："它像是一个奔向虚空的信使，怀里抱着人类文明存在的证明。这是属于一个时代的浪漫。"
- 世界树餐厅吃饭，遇到南翼主管拼桌
- 南翼主管望着窗外："现在的一切平静都来自于和平啊。"然后大口吃饭离开了
- 大萧条展厅（见[[大萧条]]）

## 最后一天——枪击

Aliya在酒店门口等Leon，突然枪声。远处沙滩乱作一团。Aliya靠在汽车旁检查自己有没有中枪，手在发抖。

她看到远处一个六七岁小女孩摔倒了，后面蜂拥的人群会把她踩死。

最终没人去救。Aliya："我不是英雄，也没必要当一个英雄。我没有错。不是我的错。这一切不是我造成的。"

## 真相

Leon用狙击枪打穿了南翼主管的脑袋。44人死亡（12人射击，32人踩踏）。贝索尼亚星球主管的女儿在踩踏中死亡。

Aliya："我早该知道这次旅行不会那么简单的。不过他们说我的行为帮他们打了掩护。难道他们带我过来的目的就是这个吗？"

后果：南翼对东翼发难，战争即将爆发。反抗军与南翼合作。
