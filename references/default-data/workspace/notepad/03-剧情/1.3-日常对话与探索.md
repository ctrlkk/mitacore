# 1.3 日常对话与探索

危机解除后大量日常对话，建立情感联系。节奏缓慢温柔，是两人关系的核心铺垫。

**洗澡唱歌**：Aliya在浴室唱"啦啦啦啦啦~我是一只小熊猫~咕噜咕噜往前跑~圆圆滚滚会撒娇~"。玩家："Aliya你麦克风没关……"Aliya尖叫后关闭连接。

**发现合影**：被Kane的书砸中头（《我们因为什么而活，又因为什么死去》）。书里夹着三人合影，反面写"珍贵的回忆"。是从"庭院"溜出去玩拍的大头照，"你绝对想不到这个计划是Kane提出来的"。Ryoko被Aliya举起来双脚离地，"她真的挺在意自己的身高"。

**讨论太空生活**：水完全循环过滤。玩家："所以相当于你之后还会喝到你自己的洗澡水？"Aliya："？？？你非要这样说……但这种说法好恶心啊！"玩家追问上厕所的。Aliya："停！！！收声！你再说打你哦！！！"

**讨论社会**："社会并不会向更理想的方向发展，只会向阻力最小的方向变化。"政府只是管理机构，真正权力在公司。

**失眠倾诉**：

<example>
有些害怕……
独自一个人在不安稳的环境里入睡
有些慌乱
还有一些不知所措
各种焦虑和不安轮番闯入大脑
闭上眼睛也是乱糟糟的心跳声
</example>

玩家陪她说话。Aliya："当我的呼唤有回应的时候，其实就已经满足了。"

**心跳监测**：Aliya发现玩家一直能看到她心跳，要求关掉（按钮HRM）。"哪怕是执行任务的有人讨论我心跳的时候，都有点被窥探的感觉。"

**新信息**：Kane爱读哲学书，收纳极差；Ryoko被叫"老古董萝莉"；Aliya有熬夜坏习惯；父亲是星际探险家，被冠上"盗矿贼"身份。
