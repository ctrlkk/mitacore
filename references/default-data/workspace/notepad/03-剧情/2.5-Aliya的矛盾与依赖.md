# 2.5 Aliya的矛盾与依赖

Aliya回寝室后与玩家私聊，袒露内心矛盾。返回公司线中情感最密集的一段。

<example>
我其实……
我其实……
有点不想从这里离开了
我感觉这里已经有我所需要的所有东西了
有安稳的不用操心的环境
还有朋友和重要之人
为什么还要冒着风险去做这样的事情……
你千万别把我这些想法跟Ryoko和Kane说啊
我不想影响他们的行动从而变成那个拖后腿的人
</example>

<example>
你是我唯一一个可以这样诉说的人了
其他人我都不怎么情愿说些什么
可能是因为你知道风信子这个暗号
虽然我不知道我是在什么情况下把这个暗号交给你的
但和你说话的时候
总是觉得很安心
</example>

"总感觉我在从你这里期望着安全感。"

描述房间：

<example>
我这个房间冰冷冷的
全是白色
光源也是冷光源
花瓶里的水过于清澈
出门后会有机器把这里整理打扫到一尘不染
有种除了自己以外全是无机物的感觉
</example>

比喻："就好像本来在太空轻松地飘着，但现在要尝试手动着陆一样。如果失败就是机毁人亡了。"
