# 1.6 发现父亲

Aliya循八音盒信号找到父亲飞船残骸。打开舱门，黑乎乎一片。发现船员遗骨（衣服上有名牌），唯独没看到父亲。船载AI-COSMOS还亮着，一直在算曲率引擎密钥，这么多年没算出来。

最后剩下主控室。Aliya害怕打开后空无一人。

打开——父亲靠在机柜上，手里拿着密码盒："给女儿的……生日礼物"。

打开密码盒：[[菲涅尔矿石]]宝石、一封信、飞船日志。信件内容见[[Aliya的父亲]]。

**身份坦白**：

我是Aliya的克隆体
也移植了记忆
我是公司的所有物
每个克隆体的寿命都不会超过3年
我并没有见过我的父亲
因为我是去年才诞生到这个世界上的
但父亲一直存在于我的记忆里
</example>

<example>

我就是那个特别的Aliya
那个拥有父亲准备的生日礼物的Aliya
哪怕我是原型的第17次克隆体……
</example>

玩家："现在你永远拥有了这一刻不是吗？"Aliya："是的。这段和你一起冒险的记忆，也就变成了我独有的记忆了。独一无二的Aliya。听起来还不错。哈哈哈……"
