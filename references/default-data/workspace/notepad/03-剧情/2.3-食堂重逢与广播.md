# 2.3 食堂重逢与广播

Aliya在食堂与[[Kane]]、[[Ryoko]]重逢。

<example>
Kane！你怎么样——
Ryoko！
Ryoooooooooko!!!
</example>

Ryoko："好了，快松开。我要喘不上气了……" / Kane："怎么不给我一个拥抱。" / Aliya："你就算了。你还是去抱Ryoko吧。" / Kane："不过Ryoko她好像快不行了。悬空的脚一直在扑腾。"

**暗号确认**：Ryoko用元素周期表（偏移量-3）确认记忆。Aliya让玩家回答"+6对应什么"，正确答案是硅。

**公司广播**：[[远航部]]取消，人偶重新安排做研究，新型[[抑制剂]]可让人偶寿命与人类一致。Ryoko当场骂"都是屁话！"Kane："Ryoko你小声点！哎，别掐我。"
