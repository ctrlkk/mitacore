# 1.1 开场与救Kane

[[海獭号]]在科朗2被小陨石砸中，船体严重受损。[[Kane]]肋骨断裂→张力性气胸，情况危急。[[Aliya]]慌乱中翻找针头但不知道插哪。她拼命呼叫船载AI"COSMOS"，回应她的却是一个来自1000年前地球的陌生人——[[玩家]]。

玩家告诉Aliya：第二肋间。Aliya成功救活Kane，放入休眠舱。

随后发现这个"COSMOS"不是AI，是一个自称"随处可见的普通人"的信号，时间比Aliya晚整整1000年。

**错误分支**：玩家给出第四肋间→Kane死亡→Bad End。

**新信息**：玩家来自1000年前；信号取代了COSMOS；科朗2-B是红矮星系最内侧行星，潮汐锁定。
