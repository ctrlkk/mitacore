# 2.6 潜入仓库计划

Aliya提出三种方案：

**方案一：通风口**。Ryoko观察到仓库顶通风管与其他房间联通，走廊有地面通风口。Aliya用植物叶片+试剂制作刺鼻物质放入通风口→安保闻到→检查→Aliya申请进入维修。

**方案二：正面进入**。观察安保动向，门口随机应变混入。"虽然听上去有些草率，但这是最简单进入仓储区的办法。"

**方案三：藏入货物**。每天固定时间卸货区物资入库，Aliya藏进货物。风险：可能有二次检查。

Aliya："我觉得哪个方式都会有自己的问题和麻烦。所以拿不定主意。"

玩家："犹豫才会失败！要试着相信自己才对。"Aliya："……你说得对。谢谢你，$v{name}。有你在身边真好。"
