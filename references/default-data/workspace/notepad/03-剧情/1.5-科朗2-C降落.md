# 1.5 科朗2-C降落

Aliya意识到她一直假装不知道的事实：公司不会来救她。

<example>
如果要在我死之前赶到这里
就需要用到很高的曲率等级
这会花掉不少的钱
而我……
并不值那么多钱……
其实我一开始就知道公司不会来救我了
我只是想忘掉这件事情
假装还会有人来救我
否则就会被绝望填满
</example>

降落科朗2-C时飞船出问题，硬着陆，手臂骨折。地表：氧气31%但含硫化氢1.3%（有毒），水含毒物质。氧气得不到补充。Aliya强撑乐观："起码我们还找到了一种新的地外植物不是吗？这可是大发现！开心点嘛……开心点嘛……"

**逃跑计划真相**：不是执行任务，船是未经审批开走的。Ryoko："Aliya，你和我们不一样。我们过太久了，已经离不开公司了。但你不一样，你还有未了的心愿。离开这里去寻找你的父亲吧。"Kane重伤后："别管我，我不希望我的存在阻挡了你的前进。让我去见Ryoko吧。"

**[[Laika]]的含义**："在财富差异到足够大的时候，人和人之间的差别比人和狗还大。公司会为他们的探索发现立起丰碑，但永远不会尊重他们的人格。"

氧气即将耗尽时，收音机收到八音盒信号——很近。循信号找到父亲飞船。

**新信息**：公司不会来救；逃跑计划真相；科朗2-C有毒；Laika的含义。
