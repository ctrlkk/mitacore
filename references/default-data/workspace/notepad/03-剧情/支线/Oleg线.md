# Oleg线

[[Kane]]让玩家联系老友[[Oleg]]。

Oleg要求证明身份："说明你的身份。否则我会拉黑你的通讯地址。"玩家说"Kane是一个工程师"，Oleg："我要的不是这种调查一下就能获得的信息。告诉我一件，是只有我和他才知道的事情。"

Kane给玩家的秘密："他第一次和他妻子约会的时候借了我的裤子。他自己的因为第一次约会太紧张，在做深蹲放松的时候撕裂了。"Kane补充："不要和Oleg说是我现在人偶的身份。因为有些丢脸……"

Oleg验证后态度稍微软化，但拒绝直接帮忙："没兴趣帮一个消失了十几年又突然出现的人。""很好，我的好奇心已经消失了。你可以滚了。"

玩家发送合影，询问Milia近况。Oleg："Milia一切都好，只是最近不在矿上工作了。这么多年了，这家伙竟然没什么变化。"

最终建议："也许你可以让Kane调查一下货舱。任何地方想要长期维持运转，一定需要外部源源不断的提供物资。找到货仓，就有可能找到货单信息。"

告别："没事了就不要再骚扰我了。"内心独白："基本上没有暴露太多信息。最好还是不要和这个家伙聊太多。"
