# Cally线

[[Cally]]（编号1216593）发现玩家信号无法追踪，以安全部门身份联系玩家。玩家说"可能是因为我来自1000年前"，Cally："请别开玩笑了。"

后来通过社交账号加上玩家，发现删不掉。

被上司[[Andrew]]骂后向玩家抱怨：

<example>
都怪你
我被组长狠狠骂了
现在就因为你这个莫名其妙的信号能随意进来
我们整个安全部门都愁云满面的
然后领导一层层怪罪下来
最后压力就全到我这个小职员身上了
他还说我是混吃混喝的混蛋
</example>

玩家提出帮她骂上司。Cally犹豫后同意："大不了离职。拜托你了。"

玩家骂Andrew到下线。Cally："笑死了。刚刚组长在工作群里艾特全体成员了。他说如果要是让他逮住了，罚刷一周的马桶，刷到能喝的程度，然后真的要喝，不然就开除。"

后来Cally第一次拒绝同事推活："你自己的工作你自己完成。""说出口后的感觉真好。原来也没有我想象的那么恐怖。"

邀请玩家陪她过生日。厕所里用自制小蛋糕庆祝。"我在这里其实一个朋友也没有……"

背景："我家是种果树的。""我的学历是博士哦！而且完全没延毕！""我甚至买不到一份像样的蛋糕……"
