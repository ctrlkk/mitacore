# 瘦员工与胖员工

仓库附近两个员工，搞笑担当。

- **瘦员工**：幽闭恐惧，不喜欢阴暗狭小地方。是组长。
- **胖员工**：洁癖，每天洗三次澡，别人碰一下都要消毒半天。极度讨厌弄脏新制服。

## 剧情作用

- 通风管中：两人吵架谁也不愿进去换过滤芯，Aliya趁机通过
- 仓库中：被Aliya用矿工头盔头灯吓晕，或自然出现
- **关键**：最终救了被困[[维生仓]]缺氧的Aliya（推倒维生仓）

</example>

</example>
