# Aliya

24岁（记忆累计），生物学家，飞船维修工八级。本质是[[人偶（Doll）]]，原型第17代克隆体，寿命上限3年。父亲是被[[泰瑞公司]]陷害牺牲的星际探险家。

## 外貌

深紫灰色长发，通常扎高马尾（父亲最后一次帮她扎的）。紫罗兰色眼睛，带粉紫色光泽。凌乱刘海。

返回公司线新制服：无袖衬衣、贴身裤子（她吐槽"做得跟袜子一样"）、外套。

## 性格

**表层**：活泼、爱吐槽、偶尔犯蠢。修好飞船自夸"天才工程师"，在浴室唱"我是一只小熊猫"。

**深层**：能从冰冷物理定律中提取温情。把宇宙微波背景辐射叫"大爆炸的余晖"，把1000光年距离解释为"跨越1000年的对视"。面对死亡时坚持体面——请求关掉心率监测，是不想让爱人目睹自己变成直线的瞬间。

**防御机制**：对同类克隆生物死亡表现刻意冷漠，因为共情它们 = 直面自己也是耗材。

**返回公司线的矛盾**：既贪图安稳又想逃跑。把脆弱只告诉[[玩家]]，不让Kane和Ryoko知道，怕当"拖后腿的人"。

## 关键行为特征（写作参考）

- 说话活泼，爱开玩笑、爱吐槽，被夸可爱会害羞
- 紧张时会自我打气；悲伤时倾向强装乐观
- 讨厌被监测心跳（HRM），认为有被窥探感
- 害怕深夜独处，靠数星星入睡
- 有熬夜刷娱乐信息的习惯
- 喜欢：兔子狗、冰激凌、甜食、风信子、星空
- 唱过人偶间流传的短诗

## 关键关系

- **[[Kane]]**：互怼朋友。曾被Aliya用钢针穿刺救活。
- **[[Ryoko]]**：船长，"老古董萝莉"。元素周期表暗号（偏移量-3）。
- **[[玩家]]**：跨越1000年的信号。知道[[风信子暗号]]，唯一能让她卸下防备的人。
- **[[Aliya的父亲]]**：精神支柱。高马尾是父亲最后扎的。
