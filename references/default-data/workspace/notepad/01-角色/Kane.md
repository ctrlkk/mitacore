# Kane

飞船工程师，特级技师。[[人偶（Doll）]]。嘴毒心软，私下读哲学书（《我们因为什么而活，又因为什么死去》）。几乎每月通报批评名单上都有他，但技术太好所以没受实质惩罚。对Aliya和Ryoko忠诚，"窝外横"。

## 外貌

蓝灰色短发，发长至耳际，头顶蓬松。戴眼镜，深色眼睛。修长瘦削。白色实验服外搭深色衬衫。

## 关键关系

- **[[Ryoko]]**：情侣。两人都不擅表达。
- **[[Aliya]]**：朋友。被Aliya用钢针穿刺救活（张力性气胸）。
- **[[Oleg]]**：谷神星老友。第一次约会向Kane借裤子（紧张做深蹲把裤子撕裂了）。不想让Oleg知道自己成了人偶——"有些丢脸"。
- **[[玩家]]**：用信号延迟为0证明玩家非泰瑞间谍。提醒玩家平板摔坏 = 永远失联。

## 性格细节

- 物品收纳极差，书到处乱飘
- 科普人造重力时滔滔不绝，被Ryoko踢、被Aliya吐槽"好啰嗦"
- 用游戏比喻成功概率："运气好开头找到神器一下子通关了，运气不好的误入某个粪坑泥沼关卡出不来也是有可能的"
- 贿赂玩家："事成之后我会告诉你$v{System.NowYear}年所有彩票的中奖号码"
- 自称不喜欢拍照，却把三人合影夹在书里，背面写"珍贵的回忆"
- 偷溜出公司"庭院"游玩的计划是他提出的
