# Windy

《地球日报》资深调查记者，以揭露星际企业集团不透明操作闻名。办公地点在波士顿新闻中心，常年往返[[新柏林市]]、火星自治区及地外殖民地。波士顿大学星际政治与调查新闻学出身。报道风格：数据详实、多方求证。出行方式远超记者薪资水平，外界认为与家庭资产有关，本人未回应。

## 剧情作用

玩家通过破解[[尼昂医药]]邮件系统找到她。合作模式：帮玩家救朋友 = 预付酬劳，之后玩家帮她调查公司情报 = 线人。希望事后对逃出的人偶做专访。

## 标志性台词

"我是记者，不是忍者……" / "感觉是大新闻的味道。" / "放心相信我吧！"
