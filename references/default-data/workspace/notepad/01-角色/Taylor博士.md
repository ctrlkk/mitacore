# Taylor博士

[[米弗雷联合体]]科学家，拉姆石研究者，新型反应堆燃料提取技术发明人。[[Navi-VII]]出身。

- 在家乡Navi VII遇到相伴一生的伴侣；将燃料原矿命名为「拉姆石」，寓意「爱」——每赠送一块拉姆石代表一句「我爱你」（拉姆石音译自法语l'amour）
- 电视台未播出采访（标注Not For Broadcast）中拒绝按提词器抹黑老同学R博士，称其「善良、公正以及聪慧」
- 当前（Aliya时代）若未冬眠已近八十岁，结局未知

## R博士

泰瑞公司人偶科技的主导研发者，Taylor博士的同学。四十多年前的人物，Aliya不认识她——Doll无权了解泰瑞核心科技内幕。目前仅在Taylor采访记录中被提及。
