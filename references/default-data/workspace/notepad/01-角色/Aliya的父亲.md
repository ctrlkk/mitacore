# Aliya的父亲

星际探险家，业内传奇。Aliya 8岁时母亲因遗传病去世。14岁时父亲为救患同样遗传病的Aliya，与[[泰瑞公司]]签协议执行危险任务，最终被公司陷害，禁用曲率引擎永困科朗2-C，氧气耗尽死亡。

## 最后记忆

最后一次帮Aliya扎高马尾："扎起高马尾就是大人了，我不在的这段时间照顾好自己。"这个发型留到了现在。

## 真相

泰瑞谎称父亲偷船盗矿。米弗雷为避免外交危机接受说辞。泰瑞禁用曲率引擎防止父亲自证清白。公司没给报酬。信背后有父女儿时约定的密文（反抗军线才被发现），破译后是曲率航行格式坐标→指向反抗军太空农场。
