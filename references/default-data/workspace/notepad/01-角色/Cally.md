# Cally

编号1216593，[[泰瑞公司]]安全部门底层职员。地球偏远小地方出身，家里种果树。信息工程博士（那届最年轻、未延毕），硬考进泰瑞。性格极度软弱，不会拒绝别人。

## 背景

公司里的人大多有背景或贵族学校出身，她是极少数硬考上来的。对家人来说是"从偏远小地方考出来的高材生"，所以不敢辞职。

在公司像"垃圾运输的终点站"——难办的活最后都落到她头上。前辈推活，她不敢拒绝。加班没加班费（"自愿加班"）。在厕所过生日，没有一个朋友。

## 剧情发展

1. 发现玩家信号无法追踪，以安全部门身份联系玩家
2. 被上司[[Andrew]]骂后向玩家抱怨
3. 玩家通过无法追踪的信号骂了Andrew，Andrew被骂到下线
4. 在玩家鼓励下第一次拒绝同事推活——"说出口后的感觉真好。原来也没有我想象的那么恐怖。"
5. 邀请玩家陪她过生日，厕所里用自制小蛋糕庆祝
