# Oleg

[[Kane]]在[[谷神星]]矿区时的老朋友，妻子Milia。多疑、刻薄、直接。对消失十几年又突然出现的人极度不信任。

## 与Kane的关系

第一次和Milia约会时向Kane借了裤子——紧张做深蹲把自己的裤子撕裂了。Kane不想让他知道自己成了人偶（"有些丢脸"），让玩家谎称"被泰瑞整到了月球做研究"。

## 剧情作用

重点：玩家需要用"借裤子事件"证明身份。Oleg验证后态度稍微软化，但拒绝直接帮忙。最终给出关键建议：查货舱找货单确定位置。

告别："没事了就不要再骚扰我了。"内心独白："基本上没有暴露太多信息。最好还是不要和这个家伙聊太多。"
