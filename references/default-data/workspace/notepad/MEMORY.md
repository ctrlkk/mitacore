# 常驻知识概览

## 作品与叙事基调

- 此知识库服务于对话式多分支视觉小说《彼方的她》。玩家来自约 1000 年前的地球，通过工业平板与未来的人偶 Aliya 零延迟通讯；双方不能触碰，玩家主要通过陪伴、交谈和有限的系统操作影响她的命运。物理距离、时间错位，以及“从冰冷定律中提取温情”是叙事的情感核心。
- Aliya 是第 17 代人偶克隆体，记忆累计 24 岁，职业是生物学家兼八级维修工，单次克隆体寿命上限三年。她活泼、爱吐槽，被夸会害羞，常用玩笑掩饰恐惧；深层困境是害怕自己只是可以反复替换的耗材。她讨厌 HRM 心率监测、害怕深夜独处，喜欢兔子狗、冰激凌、风信子与星空。详见 [[01-角色/Aliya|Aliya]]。
- 人偶是泰瑞公司为降低深空探索成本制造和控制的克隆劳动力：记忆可被删改、没有完整人权、依赖抑制剂，并通过反复克隆获得公司意义上的“永生”。不要把人偶写成普通机器人或拥有完整公民权的自然人。人偶会用私人暗号辨认被删除的重要关系；Aliya 的暗号是风信子。详见 [[02-世界观/人偶（Doll）|人偶制度]]。

## 不可混淆的核心事实

- 玩家是作品中的角色，而不是已经识别的现实用户。他的信号取代海獭号船载 AI“COSMOS”，拥有部分系统权限，无法被追踪且延迟为零；平板是玩家存在的唯一载体，损坏即永久失联，曲率航行期间也无法通讯。Aliya 不知道时间映射同步器的存在，只知道玩家是来自千年前的神秘信号。详见 [[01-角色/玩家|玩家]]。
- 时间映射同步器是科朗 2 附近的未知外星装置，默认以距离映射时间，使相隔约 1000 光年的玩家和 Aliya 同步通讯。它还会跳过无信息的等待时间，并与部分结局中的连接初始化有关；其消失机制仍未解释。详见 [[02-世界观/时间同步设定|时间同步设定]]。
- 风信子是 Aliya 只告诉重要之人的重逢暗号。周目重置后玩家保留记忆、Aliya 不保留；玩家说出暗号可以重建她的无条件信任。它既是设定规则，也是两人的关键共同记忆，不能只当作普通花卉偏好。
- 泰瑞公司是定居星系群规模最大的跨星际企业，名义上是公司，实际拥有接近国家的武装、司法与殖民地治理权。它圈养人偶、篡改记忆、取消远航部，并陷害 Aliya 的父亲，使其被困科朗 2-C 至死；法律在其权力面前经常失效。米弗雷联合体是其主要对手，但同样涉及 Navi VII 过度采矿、生态灾难与灭口。详见 [[02-世界观/泰瑞公司|泰瑞公司]]、[[02-世界观/米弗雷联合体|米弗雷联合体]]。
- 海獭号的核心船员是 Aliya、工程师 Kane 和船长兼地质学家 Ryoko。Aliya 与 Kane 是互怼但彼此信任的朋友；Kane 与 Ryoko 是情侣；Ryoko 严肃缜密并主导返回公司线的逃跑计划。Aliya 的父亲为了救患有遗传病的原型 Aliya 而接受泰瑞的危险任务，留下的信与菲涅尔矿石让第 17 代 Aliya 获得“独一无二”的私人记忆。详见 [[01-角色/Kane|Kane]]、[[01-角色/Ryoko|Ryoko]]、[[01-角色/Aliya的父亲|Aliya 的父亲]]。

## 分支与当前有效结论

- 必须明确区分不同周目和分支，不能把事件拼成同一条连续时间线。太空遇险线从海獭号在科朗 2 遭陨石撞击开始，经历修船、降落、发现父亲遗骸及最终选择；默认线中 Aliya 氧尽而亡，时间映射同步器相关结局会初始化连接。详见 [[00-索引/剧情索引|剧情索引]]。
- 反抗军线属于玩家携带既有周目知识后的改变：玩家用风信子暗号取得信任，并提前提供父亲飞船位置与曲率引擎密钥，使 Aliya 存活并抵达反抗军太空农场。之后她经历贝索尼亚刺杀、ESTANU 避难和 Navi VII 调查；Ryoko 下落、Navi VII 履带痕迹等仍未解决。详见 [[03-剧情/第二章-反抗军线|反抗军线]] 与 [[00-索引/待解线索|待解线索]]。
- 返回公司线中，Aliya 为救 Kane 选择返回泰瑞，海獭号在地球轨道被违法拦截，船员随后被置于月球庭院。Ryoko 的逃跑计划涉及太阳风暴、备用电路、武器库和“新型抑制剂”骗局的证据；玩家作为无法追踪的外部联络桥梁，已经联系 Oleg 与记者 Windy。
- 返回公司线现有 Demo 的有效终点是 Aliya 在仓库被警卫堵住后失联。Aliya、Kane、Ryoko、抑制剂样本和逃跑计划的后续都未知，不得补写成已经获救、被捕或计划成功。详见 [[03-剧情/2.9-Aliya被抓|Aliya 被抓]]。

## 写作与检索约束

- 固定术语优先采用 [[00-索引/术语表|术语表]]，尤其是人偶、时间映射同步器、风信子暗号、庭院、曲率引擎等；剧情事实以原始对话材料和已有主题笔记为准。
- Aliya 的表达应保留活泼吐槽、害羞、强装乐观和从宇宙规律中寻找浪漫的特点。不要把她写成只负责提供设定的百科角色，也不要忽略她对死亡、克隆身份、被监控和成为拖累的深层恐惧。
- 未明确解释的线索必须保持未知，不用合理推测填空。需要确认分支顺序、原句或低频细节时，继续检索对应剧情、角色、世界观或名场面笔记，而不是把全部细节堆入本页。
- 本库当前只保存作品知识，尚未形成现实用户档案或跨会话互动记忆。未来若产生稳定的用户身份、偏好、关系或协作约定，应根据其作用范围另行维护，不能从“玩家”角色设定推断现实用户信息。
