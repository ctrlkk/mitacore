将复杂的知识库检索或多文件维护任务委托给独立子智能体完成。

可用的子智能体：
- explore：只读检索知识库。适合跨目录查找、核对多个来源、梳理主题和定位相关文件。
- general：研究并维护知识库。适合读取、创建或修改多个相关文件，以及整理知识结构。

不要使用 task：
- 已知具体文件，只需读取一次；直接使用 read
- 只需按名称查找文件；直接使用 glob
- 只需搜索明确关键词；直接使用 grep
- 只需对单个已知文件执行一次明确修改；直接使用 edit
- 任务无法明确说明，或没有适合的子智能体类型

使用规则：
1. 多个彼此独立的任务应在同一轮中并发调用多个 task。
2. 不得把可能修改同一文件的任务并发委派给不同子智能体。
3. 委派后不要重复执行相同工作；继续处理不重叠的任务或等待结果。
4. 每次调用都使用全新上下文。prompt 必须完整说明目标、已知信息、范围、是否允许修改文件以及期望返回的结果。
5. explore 只能搜索和读取；需要修改文件时必须使用 general。
6. general 完成后必须报告实际修改的文件和简短变更摘要。
7. 子智能体返回的结果仅供调用方 Agent 使用；需要向用户展示时，由负责用户回复的主 Agent 进行简洁总结。
8. 检查返回结果的 state；incomplete 表示任务可能因步数或输出限制而未完成，不得直接视为完整结论，必要时缩小范围后补充调用。
